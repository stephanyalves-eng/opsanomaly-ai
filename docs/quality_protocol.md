# Quality validation v1 — fixed before evaluation

2026-11-21. New seed identifiers 1051,2083,4099 were not used in the earlier committed stress suite (42,43,44). Configuration and rules are fixed before executing these runs. These development seeds become inspected after execution; they are not a perpetual untouched final benchmark. No claim of dataset independence beyond the synthetic RNG draws.

Fit the existing detectors once per seed on paired clean train/calibration, as before; their parameters do not change. Add a separate quality monitor operating on raw values before imputation. Every missing cell produces an informational flag immediately. A persistent missing alert starts at the third consecutive missing observation per sensor. A repeated-value alert starts at eight consecutive observed values within absolute tolerance 1e-8 relative to a fixed run anchor. Missing observations or gaps >1.5 times training median positive cadence reset runs. This is a count-of-observations rule, not guaranteed elapsed-time duration. A feature must vary by more than tolerance in training for repeat alerts to be assessable; training constants report not-assessable rather than repeated-fault alerts. Training determines this gate and cadence; calibration only replays past context. No labels or test features set these rules.

Repeated outputs say repeated values / review, not broken sensor or causal diagnosis. A sensor can legitimately hold a constant value. Eight repetitions is an engineering default for this experiment, not a validated industrial fault threshold. Fixed absolute tolerance is unit-dependent and requires domain configuration.

Use the previous eight stress cases plus legitimate_plateau (same measurements as stuck_sensor but normal operational labels), quantized_clean (round both channels to one decimal place), and constant_sensor (temperature constant throughout train/calibration/test). All original scenarios share identical fit periods per seed. constant_sensor has a deliberately different train schema behavior and is fitted separately, never compared as if the same training values. Report all 11 cases, all 3 seeds. No severity or parameter search.

Separate targets: informational missing flags vs raw missing-cell masks (a deterministic plumbing consistency check, not ML performance); persistent/repeated alerts vs declared block-outage/stuck injection intervals (includes expected detection delay); quality alert rates on every scenario; unchanged numeric detector performance vs original operational labels. Do not OR quality flags into numeric model decisions or claim an overall ML accuracy gain. Random missingness is an informational quality issue but retains normal operational labels. A legitimate plateau exposes the ambiguity of repeated values and must not be relabeled as a fault to improve precision.

Export raw flags, run counts, assessability and descriptive evidence per sensor, row-level summaries, CSV and JSON. Include point recall, false alerts, event hit/delay/coverage, normal-control alert rates and separate unlabeled summaries. No event point adjustment. Compare old numeric methods on the same new rows; keep prior stress results intact. Limits include homogeneous synthetic signals, only three new seeds, subjective operational truth, fixed cadence/tolerance, real clocks/quantization/standby states, partial-window latency, unknown assets and stateless batch replay. No new dependency, paid service, publication or physical diagnosis.
