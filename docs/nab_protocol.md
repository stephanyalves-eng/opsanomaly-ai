Plan recorded before loading CSV values or executing model evaluation, 2026-11-21. Official source: https://github.com/numenta/NAB pinned at `ea702d75cc2258d9d7dd35ca8e5e2539d71f3140` (read-only git ls-remote). Publisher LICENSE.txt declares MIT, corroborated by .zenodo.json. Preserve copyright/permission text verbatim in a local attribution file. No raw redistribution or external publication. Repository declaration is the license basis, not a fabricated per-dataset license or guarantee of third-party provenance. License/source pages were inspected for suitability; some public label metadata was visible during source research, so this is not a blind or preregistered external trial.

Three realKnownCause series selected for operational/temperature relevance: machine temperature, ambient temperature and CPU utilization/misconfiguration. No substitution or exclusion based on metric results. Each series is fitted independently; do not pool different units, dates, equipment or contexts. First 60% distinct timestamps train, next 20% calibration, final 20% test. Fix seed 42, window 31 and calibration budget 2% from earlier implementation. No labeled filtering or test-based tuning; report positive-window membership in all partitions to reveal contamination.

The official labels are anomaly intervals. Map their endpoints inclusively to a binary window-membership label, not verified per-point fault truth. Report raw point metrics, AP/trapezoid PR and false alerts per 1,000 all observations, plus separate event-window coverage/delay with clipping at test boundaries disclosed. Do not expand alerts to fill a window and do not compute or claim the official NAB score or compare to its leaderboard. Single-class test metrics remain explicit null PR summaries. Preserve all cases, even if the final holdout contains no positive labels.

Source timestamps lack explicit timezone. Localize the source clock to UTC solely as a reproducible ordering coordinate; do not claim the publisher verified UTC, geography or true physical timing. Preserve original timestamp text in the raw file. Validate schema, strictly increasing/unique times and numeric range. Record missingness and irregular cadence; do not silently resample/drop rows. Hash every raw file, label file, license and downloaded metadata. Frozen source lock, exact partitions, parameters, model thresholds, versions and code fingerprints accompany results. Download is a separate opt-in script; evaluation is offline and never fetches data implicitly. Tests use original tiny synthetic fixtures, not downloaded NAB content.

Keep quality-rule outputs separate and descriptive: they have no independent quality/failure labels here. No precision/recall claim for quality flags on NAB. No dataset repairs or thresholds fitted to test data. Test feature values can update past-only rolling histories, never labels. Once inspected these holdouts become development evidence; future tuning requires another untouched dataset/protocol. Limitations: small convenience subset, broad/imperfect interval labels, known public benchmark, unverified source clocks and full provenance, unequal cadence, contamination and regime shifts, no unseen-asset/industrial deployment validity. No money, paid API, remote compute or publishing.
